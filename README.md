# Project Computer Graphics OpenGL

## Usage

```bash
./run.sh
```

## Controls

- Mouse: Look around
- Scroll: Zoom in and out
- WASD/ZQSD: Move camera
- Space: Move camera up
- Shift: Move camera down
- C: Switch between flat and curved track
- ESC: Close the application
